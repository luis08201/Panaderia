# Support / soporte

Contact the seller through the marketplace or channel where you obtained this edition. Include the template version, page URL, language, screen width, browser, steps to reproduce and expected/actual result. A screenshot and the exact build error help. Do not send passwords, API tokens or private customer information.

Report reproducible defects in the delivered HTML edition. Brand redesign, extra languages, payment systems, other currencies, custom integrations, migrations and native Webflow/Framer implementations should be scoped separately. Hosting accounts and subscriptions belong to the buyer.

Support duration, response times, prices and update entitlement must be specified by the seller in the actual listing before purchase. This repository does not invent a support promise or refund policy.
