# AI-generated demo imagery / imágenes de demo por IA

Updated: 2 November 2026. This document describes the revised local HTML demo assets. A local change does not deploy the public website; check the deployed release before claiming production uses these assets.

The revised demo uses **32 original images generated with the built-in OpenAI image_gen tool from text prompts**, without reference photographs: four bakery scenes and 28 product images, including the hidden sample item. There are **92 optimized WebP files** after accounting for smaller versions and the copies used by categories and Blog articles.

The subject and visual style were reviewed in a contact sheet. These are illustrative synthetic food images, not evidence of an actual bakery, actual products or identified people. No brand logos, watermarks or imitation of a named photographer were requested.

`docs/AI-IMAGE-PROVENANCE.json` records the prompt, generation tool/date and original-output SHA-256 for each image, plus dimensions and SHA-256 for every optimized file. Full original PNGs, generation records, the review sheet and the replaced legacy files are retained privately outside the public website and buyer export.

The earlier Unsplash-linked image set is no longer used by the revised local demo. Its historical source list and replaced files were archived privately; this change does not certify the rights to an older deployed version or historical ZIP.

**Buyer delivery remains unchanged in scope:** demo imagery is excluded from the HTML export. Buyers receive neutral placeholders and supply their own properly licensed photographs. A screenshot of the demo does not transfer or include the source images.

AI generation does not automatically make an image public domain or guarantee exclusive rights or non-infringement. Applicable tool terms and law still govern its use. See [OpenAI terms](https://openai.com/policies/terms-of-use/), `docs/RIGHTS.md` and `THIRD-PARTY.md`.
