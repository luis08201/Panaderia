Your first steps / Primeros pasos

Make the bakery yours.

A practical setup guide for the HTML edition. Choose your language below.

EnglishEspañol

Start here

  1. Preview locally. Install Node.js 20 or later from its official website. In the project folder run npm run dev and open http://127.0.0.1:47823.
  2. Connect Pages CMS. Put your copy in your own GitHub repository, connect it to Pages CMS, and select that repository. Its configuration is in .pages.yml.
  3. Add your identity. In Settings change the business name, tagline, phone, WhatsApp (country code and digits), address, opening hours, social links and website URL. Replace the logo SVG in the page headers/footers, the icon sprite and favicon.svg. The written guide maps these files.
  4. Replace sample content. Edit products, categories, promotions, Home, About and Blog collections. Keep existing IDs when editing translations. Add your own licensed images through the CMS; demo photographs are not part of the buyer export.
  5. Update Spanish. Open “Contenido en español” in Pages CMS. Keep entries aligned with their English counterparts and preserve section/gallery order. New English records also need Spanish entries; see the written buyer guide.
  6. Choose your look. Preview the style guide. Shared colors, sizes and spacing live in css/tokens.css. Prices are USD; changing currency requires coordinated code, content and translation edits described in the written guide.
  7. Build and publish. Run npm test and npm run build. Publish dist/ only. Cloudflare Workers uses wrangler.jsonc; set your own worker name. Keep the build command enabled.
  8. Check before opening. Test both languages, search, navigation, mobile layouts and real contact links. Turn off the demo notice only after entering real contact details. Set your domain and rebuild for updated canonical links and sitemap.

Empieza aquí

  1. Prueba en tu equipo. Instala Node.js 20 o superior desde su web oficial. En la carpeta del proyecto ejecuta npm run dev y abre http://127.0.0.1:47823.
  2. Conecta Pages CMS. Guarda tu copia en un repositorio propio de GitHub y selecciónalo en Pages CMS. El archivo .pages.yml configura los campos de edición.
  3. Agrega tus datos. En Configuración cambia nombre, lema, teléfono, WhatsApp con código de país, dirección, horarios, redes y dominio. Sustituye el logo SVG en encabezados, pies, iconos y favicon.svg. La guía escrita indica los archivos.
  4. Personaliza el contenido. Edita productos, categorías, promociones, Inicio, Nosotros y Blog. Conserva los identificadores existentes al editar traducciones. Sube tus propias fotos con permiso de uso; el paquete del comprador incluye imágenes neutras.
  5. Actualiza español. Abre “Contenido en español” en Pages CMS. Mantén el contenido equivalente al inglés y conserva el orden de secciones y galerías. Los registros nuevos necesitan también su entrada en español; consulta la guía escrita.
  6. Define el estilo. Usa la guía de estilo. Los colores y tamaños compartidos están en css/tokens.css. Los precios usan USD; cambiar moneda requiere ajustar código, contenido y textos como explica la guía escrita.
  7. Publica. Ejecuta npm test y npm run build. Publica solo dist/. Si usas Cloudflare Workers cambia el nombre en wrangler.jsonc y conserva el comando de construcción.
  8. Verifica la apertura. Prueba ambos idiomas, buscadores, navegación, móvil y contacto real. Desactiva la demo después de agregar tus datos. Configura tu dominio y reconstruye el sitio para actualizar SEO y sitemap.
